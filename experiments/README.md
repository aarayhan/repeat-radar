# Experiments

Scripts behind `brain/03_EVIDENCE.md`. Run from this folder after placing `online_retail_II.xlsx` in it.

1. `python load_data.py` creates `retail.csv`.
2. `python stock_gate.py`, `stock_gate_variants.py`, `stock_intervals_and_aggregate.py` reproduce section A.
3. `python customer_repeat.py` reproduces section B.

Data: UCI Online Retail II, CC BY 4.0. Not committed.
